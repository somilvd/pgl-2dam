# Lista de extensiones recomendadas para cada lenguaje
## 1. JavaScript
- Prettier - Code formatter: Automatiza el formateo del código para mantenerlo ordenado y estandarizado de forma global.
- ESLint: Analiza el código en tiempo real para encontrar errores sintácticos y asegurar buenas prácticas.
- JavaScript (ES6) code snippets: Introduce atajos de teclado rápidos para generar bloques de código comunes (bucles, promesas, métodos).

## 2. TypeScript
- TypeScript Error Translator: Traduce los indescifrables e interminables mensajes de error de TypeScript a un lenguaje humano y comprensible. 
- Move TS: Actualiza de forma automática todas las rutas de importación cuando mueves un archivo .ts o .tsx de carpeta.
- Total TypeScript: Ofrece consejos interactivos y explicaciones visuales sobre los tipos al pasar el cursor por encima del código.

## 3. React
- ES7+ React/Redux/React-Native snippets: Genera la estructura completa de componentes funcionales e hooks en un segundo escribiendo abreviaciones (como rafce).
- Auto Close Tag: Cierra automáticamente las etiquetas HTML y componentes de JSX al escribir la etiqueta de apertura.
- Auto Rename Tag: Cambia simultáneamente la etiqueta de apertura y cierre en tus archivos JSX/TSX si decides renombrar un elemento.

## 4. React Native
- React Native Tools: La extensión oficial de Microsoft que te permite ejecutar y depurar tu aplicación (iOS y Android) de forma directa desde la paleta de comandos de VS Code, sin depender al 100% de la terminal externa.
- Color Highlight: Indispensable para móviles. Muestra una vista previa del color exacto detrás de tus códigos hexadecimales o RGBA dentro de tus objetos StyleSheet de React Native.
- Console Ninja: Muestra los console.log() de tus componentes y peticiones a la API directamente en el editor al lado de la línea de código donde se ejecutan, ideal para no perder de vista el flujo de datos mientras pruebas en el simulador.
- Turbo Console Log: Te permite generar un console.log ultrarrápido y perfectamente etiquetado con solo presionar un atajo (Ctrl + Alt + L) sobre cualquier variable o estado de tus componentes.

## 5. Expo

- Expo Tools: Proporciona autocompletado inteligente en archivos de configuración (app.json), validación de esquemas y soporte de depuración específico para el ecosistema 
- Expo.React Native Tools: Permite depurar el código de React Native directamente desde el entorno de Visual Studio Code.
